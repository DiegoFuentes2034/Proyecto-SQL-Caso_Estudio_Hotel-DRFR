# Proyecto-SQL-Caso_Estudio_Hotel-DRFR
Transformando datos en decisiones estratégicas.

Este proyecto desarrolla un análisis de datos aplicado al sector hotelero, tomando como caso de estudio al holding DataAndino. Mediante SQL y Databricks, se explora el comportamiento de las reservas, los patrones de cancelación y las posibles pérdidas económicas que afectan la rentabilidad del negocio.

El trabajo comprende procesos de exploración, limpieza, transformación y consulta de datos, aplicando funciones SQL, agregaciones, subconsultas, operaciones JOIN y análisis de hipótesis.

Mi enfoque es convertir conjuntos de datos en información comprensible, identificar problemas a partir de evidencia y plantear oportunidades de mejora mediante el análisis. Cada consulta representa un paso hacia una mejor comprensión del negocio y una toma de decisiones basada en datos.
